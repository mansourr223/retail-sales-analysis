# 📊 Retail Store Sales Analysis

A interactive data analysis web application built with **Streamlit** 
that provides deep insights into retail store transactions.

## 🔍 Features
- Sales trends by category and region
- Customer segment behavior analysis
- Discount impact on total spending
- Return rate analysis
- Payment method breakdown
- Interactive Plotly charts

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## 📁 Dataset
10,000+ retail transactions with columns including:
- Transaction details (ID, date, category, item)
- Customer info (ID, segment)
- Financial data (price, discount, total spent)
- Ratings & returns

## 🚀 Run Locally
pip install -r requirements.txt
streamlit run app.py
